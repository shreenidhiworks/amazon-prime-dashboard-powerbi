# amazon-prime-dashboard-powerbi
This Power BI dashboard project explores and visualizes a dataset of Amazon Prime Video. The goal is to identify platform trends such as genre distribution, release year trends, country-wise production, and content type (Movies vs. TV show) composition. This was built as part of a learning exercise in data visualization and storytelling using Power BI.
